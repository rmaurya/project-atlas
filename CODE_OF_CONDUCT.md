# Code of conduct

## The short version

Be straightforward and be kind. Argue about the work, not the person making it.

## What is expected

- **Say what you mean, specifically.** "This breaks on a monorepo because the taxonomy assumes one docs
  directory" is useful. "This is badly designed" is not.
- **Assume the other person read the code.** If they did not, point at the line rather than at them.
- **Disagreement is welcome and expected.** This project has opinions written down precisely so they can be
  argued with. Bring the case against.
- **Accept a decision once it is made**, or make a better argument. Not both, repeatedly.

## What is not acceptable

Harassment, personal attacks, demeaning comments about people or groups, unwelcome attention, publishing
others' private information, and sustained disruption of a thread after a decision has been made.

## Scope

Issues, pull requests, discussions, commit messages, and any space where you are representing this project.

## Enforcement

Report to **hi@rajneeshmaurya.com**. Reports are read by the maintainer and kept confidential.

Response is proportionate and, in order: a private word, a public correction, a temporary block, a permanent
one. Most things stop at the first.

This is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), shortened to
the parts this project can actually enforce.
